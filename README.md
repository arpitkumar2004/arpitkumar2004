##  Research

### Native Language Identification from L2 English Speech &nbsp;&nbsp;

**Advanced Technology Development Centre (ATDC), IIT Kharagpur** &nbsp;·&nbsp; May – Jul 2025  
Supervisor: **Prof. Shyamal Kumar Das Mandal**

Benchmarked 7 deep learning architectures on the NISP dataset — from CNN and ResNet-18/50 baselines to transformer-based SSL fusion models — across 5 Indian L1 languages (Hindi, Telugu, Tamil, Kannada, Malayalam).
**Final model:** Frozen Wav2Vec2 + WavLM encoder layers → BiLSTM head. **0.88 validation accuracy**, state-of-the-art on this task. UMAP embeddings revealed tight, well-separated Telugu/Malayalam clusters and quantifiable Hindi-Tamil phonetic overlap — interpretable signal beyond the classification score.
